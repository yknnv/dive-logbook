# Как вносить правки

*Contributions are welcome; the guide below is in Russian, but issues and
pull requests in English are fine.*

Книга готовится к печати и заполнению ручкой. Ошибку вёрстки после
типографии уже не исправить, поэтому требования жёстче обычного.

## Что полезнее всего

- **Фактические ошибки в справочнике.** Самое ценное. Приложите источник:
  стандарт обучающей организации, руководство производителя, таблицу.
- **Ошибки вёрстки:** наложения, вылезающий за поля текст, разъехавшиеся
  колонки. Приложите номер страницы и скриншот из PDF.
- **Опечатки** в русском и английском.
- **Новые страницы справочника** — сначала issue с планом, потом код.

## Перед пул-реквестом

```bash
pip install -r requirements.txt
./build.sh
```

Сборка обязана пройти без ошибок, `check_margins.py` — не найти ни выхода
за поля, ни наложений. То же самое проверит CI.

Дальше — откройте изменённые страницы в PDF и посмотрите глазами.
Автопроверка ловит геометрию, но не ловит смысл.

## Инварианты

Полный список — в [CLAUDE.md](CLAUDE.md), он же брифинг для ИИ-агентов.
Коротко:

1. Отступы задаются константами `GAP_*` из `src/reference.py`. Один тип
   элемента — один отступ во всей книге. Подгонка интервала под конкретную
   страницу запрещена.
2. Не помещается — режьте содержимое, а не интервал. Кегль основного
   текста не уменьшать.
3. Монохром. Только оттенки чёрного.
4. Номера страниц не печатаются: листы съёмные.
5. Подписи полей двуязычные.
6. Числовые ориентиры зависят от обучения, снаряжения и местных правил —
   там, где это существенно, нужна оговорка в тексте.
7. Тон профессиональный, без назидательности.
8. Не трогайте страницы, которых правка не касается.

Геометрию рисуйте вектором в `src/figures.py`, а не картинкой: неверная
фигура в печатном справочнике хуже отсутствующей.

## Формат постановки правки

Если вы описываете правку словами — issue или задание агенту:

```
Файл: src/reference.py, функция p_<имя>
Сейчас: «<точная цитата>»
Заменить на: «<новый текст>»
Причина: <почему>
Приоритет: CRITICAL | SHOULD | OPTIONAL
```

Ищите по цитате, а не по номеру страницы: номера смещаются при любом
изменении объёма.

## Коммиты и ветки

- ветка от `main`, имя вида `fix/gas-planning-rmv` или `page/deco-tables`
- один коммит — одна осмысленная правка
- в PR укажите, менялось ли число страниц; если да — почему

## Иллюстрации

Задание составляется по [docs/illustration-brief-template.md](docs/illustration-brief-template.md).
Требования к файлу: монохром, белый фон, без текста в кадре, от 2048 px по
длинной стороне. Дальше `python3 tools/prepare_illustrations.py <папка> <mapping.txt>`.
