# CLAUDE.md

Инструкции для работы с этим проектом. Прочитай целиком перед первой правкой.

## Что это

Журнал погружений формата A5 — печатный журнал, справочник и памятка. Вёрстка описана
кодом на Python через reportlab: бинарного макета нет, книга целиком
пересобирается из исходников. Готовится к реальной печати и заполнению
ручкой, поэтому ошибки вёрстки стоят дорого — исправлять их после
типографии уже поздно.

Объём: 130 страниц, из них 42 разворота под записи.

## Команды

```bash
./build.sh                                  # собрать и проверить
python3 src/logbook.py                      # только собрать
python3 src/check_margins.py dist/<файл>.pdf  # только проверить
```

Сборка обязательна после любой правки. Проверка обязательна перед тем,
как отчитаться о завершении.

## Карта файлов

| файл | что внутри |
|---|---|
| `src/logbook.py` | геометрия страницы, палитра, примитивы вывода, обложка, страница данных, карточки записей, сборка книги |
| `src/reference.py` | справочный раздел: одна функция `p_<имя>(pno)` на страницу, список `pages` задаёт порядок |
| `src/figures.py` | векторные схемы, функция на схему |
| `src/check_margins.py` | три проверки готового PDF |
| `assets/images/` | иллюстрации, монохромные PNG |
| `assets/fonts/` | Carlito, SIL OFL 1.1 |

## Инварианты

Нарушать нельзя. Всё это оплачено ошибками, каждая из которых доходила до
готового PDF.

1. **Отступы задаются константами** `GAP_TEXT`, `GAP_LIST`, `GAP_TABLE`,
   `GAP_FIG`, `GAP_NOTE` из `src/reference.py`. Один тип элемента — один
   отступ во всей книге. Подгонка интервала под конкретную страницу
   запрещена: именно из-за неё вёрстка разъезжается, и одинаковые
   заголовки начинают стоять по-разному.
2. **Не помещается — режь содержимое, а не интервал.** Варианты по
   убыванию предпочтительности: сократить текст, уменьшить высоту
   картинки, разделить страницу надвое. Кегль основного текста не
   уменьшать.
3. **Монохром.** В палитре только оттенки чёрного, `ACCENT` равен чистому
   K. Цвет в иллюстрациях при печати в одну краску станет серым пятном.
4. **Номера страниц не печатаются.** Листы съёмные, порядок задаёт
   владелец. `folio()` намеренно пустая.
5. **Подписи двуязычные.** `field(c, x, y, w, "русский", "english")`:
   русское название плотно чёрным, английское светлее и мельче, кегль
   подбирается под ширину колонки автоматически.
6. **Фактология проверяется.** Числовые ориентиры и процедуры зависят от
   обучения, снаряжения, местных правил и плана — там, где это
   существенно, в тексте нужна оговорка. Не выдумывать значения, не
   подавать условное как универсальное правило.
7. **Тон профессиональный.** Коротко, без назидательности и без
   эмоциональных усилений вроде «это убивает». Терминологию не упрощать
   до бытовой.
8. **Не трогать страницы, которых задача не касается.** Стилистические
   улучшения по своей инициативе не вносить.

## Как устроена страница справочника

```python
def p_example(pno):
    x, w, y = head(pno, "заголовок", "TITLE", "вводный абзац или None")
    y -= sub(x, w, y, "подзаголовок", "SUBTITLE")
    y -= bullets(x, y, w, ["пункт", "пункт"]) + GAP_LIST
    y -= table(x, y, w, [("колонка", "column")], [["строка"]], [1.0]) + GAP_TABLE
    y -= blank_rows(x, y, w, [("поле", "field")], [1.0], 8) + GAP_TABLE
    y -= wrap(x, y, w, "абзац") + GAP_TEXT
    y -= img(c, "имя-файла", x, y, w, 40 * mm) + GAP_FIG
    y -= caution(x, y, w, "врезка") + GAP_NOTE
    return x, w, y
```

Есть декларативный вариант `figpage(pno, title, title_en, intro, blocks)`,
где блоки — пары `("fig" | "img" | "cap" | "sub" | "bul" | "tab", аргумент)`.

Новую страницу нужно добавить в список `pages` — иначе она не попадёт в
книгу. Порядок в списке определяет порядок в книге.

## Как устроена схема

В `src/figures.py`. Функция принимает `(c, P, x, y, w)` и возвращает
израсходованную высоту. Цвета берутся из `P`: `INK`, `ACCENT`, `LABEL`,
`LABEL2`, `RULE`, `GRID`, `FAINT`. Готовые примитивы: `arrow`, `boat`,
`axes`, `polyline`, `_t` для текста с межбуквенным интервалом.

**Всё, где важна геометрическая точность, рисуй вектором, а не отдавай
генератору изображений**: углы секторов огней, формы навигационных
знаков, пропорции графиков, ход верёвки в узле. Неверная фигура в
печатном справочнике хуже отсутствующей картинки.

## Как добавить иллюстрацию

1. Задание составляется по `docs/illustration-brief-template.md`.
2. Требования к файлу: монохром, белый фон, без текста в кадре, от
   2048 px по длинной стороне.
3. `python3 tools/prepare_illustrations.py <папка> <mapping.txt>` —
   обрежет поля, переведёт в серое, разложит под нужными именами.
4. Вставить блоком `("img", ("имя", высота_мм, "подпись"))`.

## Формат постановки правки

```
Файл: src/reference.py, функция p_<имя>
Сейчас: «<точная цитата>»
Заменить на: «<новый текст>»
Причина: <почему>
Приоритет: CRITICAL | SHOULD | OPTIONAL
```

**Ищи по цитате, а не по номеру страницы.** Номера смещаются при любом
изменении объёма: страница 27 после добавления одного разворота
становится страницей 29.

## Грабли

Реальные случаи из истории проекта. Все повторяемы.

- **Дублирующиеся определения функций.** При вставке новых страниц легко
  получить две функции `p_<имя>` в одном файле. Python берёт последнюю,
  а правка через `str.replace` попадает в первую — и выглядит так, будто
  ничего не изменилось. Проверка:
  `grep -c "def p_имя" src/reference.py`.
- **Неоднозначный якорь для замены.** Строка вроде `"что помнить"`
  встречается на нескольких страницах. Срез по `str.index` вырежет кусок
  между разными функциями и разрушит файл. Привязывайся к телу конкретной
  функции.
- **`open(p, "w").write(f(p))`** обнуляет файл до чтения: аргументы
  вычисляются слева направо. Сначала читай в переменную.
- **Проверка наложений посимвольная, а не построчная.** Русская подпись и
  английский дубль стоят на одной базовой линии разным кеглем; построчное
  сравнение даёт ложные срабатывания.
- **Ретушь картинок автоматикой** на мелкой текстуре оставляет
  артефакты. Если в партии нет служебных меток, ретушь не нужна.
- **Карточка записи занимает разворот** и должна начинаться с чётной
  страницы, иначе в кольцах разъедется. В сборке есть проверка чётности,
  не ломай её.

## Перед тем как отчитаться

1. `./build.sh` отработал без ошибок.
2. `check_margins.py` не нашёл ни выхода за поля, ни горизонтальных, ни
   вертикальных наложений.
3. Изменённые страницы отрендерены и просмотрены.
4. Число страниц изменилось только если это было целью.
5. Скажи прямо, что не удалось сделать и почему. Не выдавай частично
   применённую правку за выполненную.
